# VoidGames
VoidGames is an open-source gaming platform (licensed under `AGPL 3.0`) created using *vibe coding*.
Key aspects:
## 1. Games and TOML
The `index.html` file reads the `games.toml` file to display all the games in the interface.

The games follow a minimalist approach and are designed for quick play sessions.


## 2. Updates
We follow the **x.y.z** versioning method.
The rules are:
**z** represents a patch or a new game.
**y** increments (e.g., 1.0.9 + 1 = 1.1.0).
**x** represents major changes or version shifts (e.g., 1.9.0 → 2.0.0; note: 1.9.0 ≠ 2.0.0, it would become 1.10.0).


## 3. Branches and stability
We use `main` and `dev` branches.
Changes and games are tested in the `dev` branch before being merged into `main`.


## 4. Availability on Web
It is currently **available via GitHub Pages**: [VoidGames](https://codera64.github.io/VoidGames/index.html)


## 5. Future plans
Plans for upcoming versions:
* **New games**
Adding more games to the platform to expand the entertainment library.
* **Platform migration**
There are plans to migrate the site from GitHub Pages to Cloudflare Pages in the future to improve certain features.
**Availability in native**
There are also plans to port the platform to **Android and Linux**.
**Experimental** efforts are already underway for Android via Repository:
[VoidGames_Android](https://GitHub.com/CoderA64/VoidGames_Android/)


It will also **come to Linux**.
For now, it remains **experimental** and **only on Android**.
